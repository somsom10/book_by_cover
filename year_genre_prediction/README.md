# TEXTile Factory — Evolution in Book Summaries

Dataset: [CMU Book Summary Dataset](http://www.cs.cmu.edu/~dbamman/booksummaries.html), 16,559 books with plot summaries, genres, and publication years.

## What this does

Predicts genre and publication year from book plot summaries, and checks (via unsupervised clustering) how much of that signal survives without labels. Also looks at how writing style and genre mix shift across decades.

## Results

| Task | Best model | Score |
|---|---|---|
| Genre classification (multi-label) | Linear SVC (C-tuned, balanced) | micro-F1 = 0.629, macro-F1 = 0.604 |
| Year regression | Ridge | MAE = 11.1 years, R² = 0.24 |
| Decade classification | Linear SVC | Accuracy = 0.400, macro-F1 = 0.312 |

## Setup

```bash
pip install -r requirements.txt
python -c "import nltk; nltk.download('punkt'); nltk.download('stopwords'); nltk.download('wordnet')"
```

Place the dataset at `data/booksummaries.txt` (tab-separated, no header).

## Run

```bash
python main.py --data data/booksummaries.txt
```

This trains all models and writes figures/models to `outputs/`.

## Project structure

```
src/
  data_loader.py           load and parse the CMU TSV, genre/year extraction
  preprocessor.py          text cleaning, lemmatization, text statistics
  correlation_analysis.py  Pearson/Spearman correlations, keyword trends
  genre_classifier.py      multi-label classification (LR, LinearSVC, NB)
  year_predictor.py        year regression (Ridge, LinearSVR) + decade classification
  clustering.py            KMeans on TF-IDF+LSA, cluster purity analysis
  visualizations.py        all plot functions, save to outputs/figures/

outputs/
  figures/                 PNG plots generated by main.py
  models/                  saved models (joblib): genre_best.pkl, year_regression_best.pkl, decade_best.pkl
```

## Features

- Word TF-IDF — unigrams + bigrams, 50k features, sublinear TF
- Character n-grams — 3–5 chars, 30k features, captures morphology/style
- Text statistics — word/sentence/character counts, unique words, lexical diversity, avg word/sentence length
- `class_weight='balanced'` to handle the genre imbalance (Fiction outnumbers Thriller 5:1)
